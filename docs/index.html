public class HcepGazeController : MonoBehaviour
{
    public Transform leftEyeBone, rightEyeBone;
    private HcepStreamClient _client;

    void Start() =>
        _client = new HcepStreamClient("ws://localhost:5000/ws/stream");

    void Update()
    {
        var s = _client.LatestState; if(s==null) return;
        Quaternion q = Quaternion.Euler(s.PitchDeg, s.YawDeg, 0f);
        leftEyeBone.localRotation  = Quaternion.Slerp(leftEyeBone.localRotation, q, Time.deltaTime*12f);
        rightEyeBone.localRotation = Quaternion.Slerp(rightEyeBone.localRotation, q, Time.deltaTime*12f);
        if(s.BackchannelNodRequested) GetComponent<Animator>().SetTrigger("Nod");
    }
}
void AMyAvatar::Tick(float dt)
{
    Super::Tick(dt);
    if(!GazeCtrl) return;
    FRotator EyeRot(-GazeCtrl->PitchDeg, GazeCtrl->YawDeg, 0);
    FRotator Smooth = FMath::RInterpTo(
        LeftEye->GetRelativeRotation(), EyeRot, dt, 12.f);
    LeftEye->SetRelativeRotation(Smooth);
    RightEye->SetRelativeRotation(Smooth);
    GetMesh()->GetAnimInstance()->SetVariableFloat(
        "HcepMode", (float)GazeCtrl->CurrentMode);
    if(GazeCtrl->bBackchannelNod) PlayAnimMontage(NodMontage);
}

Scientific Foundation

Built on Peer-Reviewed Research

Every HCEP signal, threshold, and timing value is grounded in the published literature.

Argyle & Cook (1976)
Social Triangle Gaze — humans scan L.Eye→R.Eye→Mouth at ~3 fixations/sec during engaged conversation.
→ SocialGazeController 340ms dwell target
Bavelas et al. (2000)
Backchannel nods occur at 1–3 per 10 seconds of active listening.
→ BackchannelController 2.2s onset, 6.5s repeat
Dimberg et al. (2000)
Facial expression mirroring occurs with 200–400ms biological reaction delay (emotional contagion).
→ ExpressionMirror reaction delay range
Duncan (1972)
Speaker turn-yielding is signalled by gaze toward listener, syntactic completion, and pause.
→ Silence Protocol speak-invitation rules
Hall (1966)
Proxemic zones: Intimate <0.45m, Personal 0.45–1.2m, Social 1.2–3.7m, Public >3.7m.
→ TorsoAnalyzer ProxemicZone + gaze amplitude halving
Jaworski (1993)
Silence is among the most powerful communicative acts — not the absence of communication.
→ SilenceProtocolEvaluator 7 evidence-based rules
McGurk & MacDonald (1976)
Visual mouth movement is a first-class speech perception channel; inaccurate lip sync degrades intelligibility.
→ 22-row VisemeController, phoneme-accurate lip sync
Ekman & Friesen (1982)
Genuine (Duchenne) smiles involve orbicularis oculi (AU6). Social smiles lack this marker.
→ ExpressionMirror Duchenne via OuterBrowRaiser threshold

Common Questions

Everything you need to know about HCEP, its science, and its engineering.

LOGIC — analytical processing; structured gaze, frequent upper-left aversion.
AFFECT — emotional engagement; sustained eye contact, Social Triangle scanning, pupil dilation.
SPIRIT — deep rapport; prolonged mutual gaze, synchronized blink, minimal aversion.
HEART — empathic resonance; soft-focus gaze, lower-face attention, slow saccades.
THINK — internal processing; gaze aversion, defocused, reduced blink rate.

The classifier uses a 5-frame hysteresis buffer and confidence cone threshold, achieving κ=0.8084 against human raters across 6,000+ labeled frames.
Primary: Microsoft Kinect v1 (Xbox 360 sensor) via USB. HCEP interfaces directly with the native Kinect 1.0 SDK via COM interop and P/Invoke — no managed SDK wrapper required.

Fallback: Any USB webcam supported by OpenCV. The fallback uses a PnP solver on detected face landmarks at reduced accuracy.

Platform: Windows 10/11 x64 only (.NET 9.0 runtime required).
Standard trackers assume coaxial alignment between camera and eyes. When the camera is off-centre (laptop webcam, mounted Kinect), standard tracking produces a systematic angular error proportional to the off-axis distance.

True Gaze™ corrects this by computing the physical pupil offset relative to the eye-socket centre in 3D camera space using a PnP head-pose solver and the binocular convergence formula atan(IOD/2 / distanceM), then applying a calibrated parallax correction matrix.
Direct API: OpenAI, Anthropic, Google Gemini
OpenAI-compatible: Mistral, xAI (Grok), Cohere, OpenRouter, DeepSeek, Groq, Together AI, Fireworks AI, Perplexity, AI21 Labs, Replicate, Hugging Face, Azure OpenAI, Amazon Bedrock, Nvidia NIM, Cerebras, Moonshot AI
Local SLMs: Ollama and Llama.cpp

All API keys stored in Windows Credential Manager — never in plain text. A cloud circuit breaker (3 failures → 30s cooldown) prevents hammering failed providers.
The Silence Protocol is HCEP's answer to: when should an AI NOT speak?

Seven evidence-based rules (Jaworski 1993; Duncan 1972) determine when SilenceProtocolActive = true:
• THINK mode + gaze aversion → user is internally processing
• Sustained brow furrow (>3s) → deep cognitive engagement
• Speech + away-gaze → user is thinking aloud
• Late night (22:00+) + HEART mode → maximum attunement
• Direct gaze toward avatar → floor-yield; speak now

HCEP is the first AI framework that knows when to be silent.
Phase 10 transforms HCEP from a perceptual system into a bidirectional social agent:

BackchannelController: Generates nods after 2.2s of continuous human speech, repeating every 6.5s — matching natural listening rhythm (Bavelas et al. 2000).

ExpressionMirror: Detects LipStretcher ≥0.30 (smile), distinguishes Duchenne from social smiles via OuterBrowRaiser, then mirrors with 200–400ms biological delay (Dimberg et al. 2000).

SocialGazeController: In AFFECT/SPIRIT, drives social-triangle scanning ~3 fix/sec. In THINK, lateral gaze aversion. Amplitude halved inside the intimate zone (<0.45m, Hall 1966).
Unity: Add HcepGazeController.cs from the SDK to your avatar. Configure WebSocket endpoint (ws://localhost:5000/ws/stream). The script drives eye bone rotations, triggers nod animations, and exposes HCEP mode to your Animator.

Unreal Engine: Add HcepGazeController.h/.cpp to your project. Drives MetaHuman eye socket bones directly. Blueprint nodes for expression graph wiring.

Both are in the sdk/ folder.

Phase 11 replaces the rule-based 5-mode classifier with a trained transformer: 12-layer, 256-dim, 8-head attention over 150ms temporal windows, trained on 50,000+ labeled multimodal frames.

Target: κ ≥ 0.92, accuracy ≥ 93% (vs. current κ=0.81, 84.6%). A distilled SLM will be available for on-device deployment (<100MB, <10ms inference). Cultural adaptation heads for East Asian, Western, and MENA interaction norms are planned. ETA: Q2 2027.
Kinect v1: κ=0.8084 and 84.55% mode classification accuracy using depth-assisted PnP and FaceTrackLib's 87-point 3D Candide-3 mesh.

Webcam (OpenCV fallback): The True Gaze™ parallax correction still applies, but without depth data the PnP solver relies on 2D landmark distances against anthropometric priors, reducing accuracy by approximately 10–15%.

For research and clinical applications, Kinect v1 or equivalent structured-light depth sensors are recommended.
